# Youtube Downloader Tool

A small windows app that can download selected YouTube videos.

## Using the app

- Open the app
- Paste a YouTube video link
- Click **Download Video**
- Decide where you would like to save the video

Should only be used to doiwnload videos you own or have permission to download

## Built using

-Python
-Tkinter
-yt-dlp
-FFmpeg
-Deno
